Student Report Card Management System

The Student Report Card Management System is a beginner-friendly Python project that simulates a simple student record management application. Users can add student details and subject-wise marks, and the program automatically calculates the total marks, percentage, grade, and pass/fail status. It also provides options to search for students and identify the class topper through a menu-driven interface.

This project helps in understanding:

User input handling
Lists and data storage
Conditional statements
Loops
Functions
Searching techniques
Arithmetic calculations
Menu-driven application development

Tech Stack: Python

Features:

Add multiple student records
Stores student details using Python lists
Calculates total marks and percentage
Assigns grades based on percentage
Determines pass/fail status based on individual subject marks
Displays all student records
Search student by Roll Number
Search student by Name
Displays the Class Topper
Uses functions to reduce code duplication and improve readability
Simple and user-friendly command-line interface
